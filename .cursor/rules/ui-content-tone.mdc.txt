# UI and Content Tone Rules

## 디자인 방향

- 따뜻하고 소박한 가족 농장 느낌을 유지한다.
- 과한 쇼핑몰 느낌을 피한다.
- 할인, 이벤트, 마감 압박 UI를 사용하지 않는다.
- 카드 UI는 부드러운 라인과 넉넉한 여백을 사용한다.
- CTA는 "구매하기"보다 "예약 주문하기"를 우선 사용한다.
- 모바일에서 먼저 보기 좋은 구조로 만든다.

## 컬러 방향

- 배경은 따뜻한 아이보리 또는 연한 복숭아색 계열을 사용한다.
- CTA는 복숭아색 계열을 사용한다.
- 본문 텍스트는 진한 브라운/차콜 계열을 사용한다.
- 너무 강한 빨강, 검정, 네온 컬러는 피한다.

## 문장 톤

- 지인에게 조심스럽게 소개하는 말투로 작성한다.
- 과장하지 않는다.
- 판매 압박을 주지 않는다.
- 정중하지만 딱딱하지 않게 작성한다.
- 중학생도 이해할 수 있는 쉬운 문장으로 작성한다.

## CTA 문구 우선순위

권장:
- 예약 주문하기
- 네이버폼으로 예약하기
- 복숭아 예약 주문하기
- 필요하신 분만 편하게 예약해 주세요

비권장:
- 지금 바로 구매하기
- 특가로 구매하기
- 마감 전 구매하기
- 놓치면 후회합니다
